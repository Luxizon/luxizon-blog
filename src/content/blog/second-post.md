Linux 的文件权限，可以从三个问题理解：**谁在访问、访问什么、允许做什么？**

## 先读懂权限位

```text
-rw-r-----  1 user developers  1024 Oct 2 10:00 notes.txt
```

第一位表示文件类型，后面的九位分成三组，分别对应所有者、所属组与其他用户。

| 权限 | 普通文件 | 目录 |
| --- | --- | --- |
| r | 读取文件内容 | 列出目录中的名称 |
| w | 修改文件内容 | 修改目录项，通常还需要 x |
| x | 执行文件 | 遍历目录、访问其中的路径 |

目录的执行权限并不是“执行这个目录”，而是允许在路径解析时穿过它。

## 从明确意图开始修改

```bash
# 查看文件权限
ls -l notes.txt

# 所有者可读写，同组用户可读，其他用户无权限
chmod 640 notes.txt
```

符号模式也能清楚地表达修改意图，例如 `chmod u+x script.sh` 为文件所有者添加执行权限。

## 不要用过大的权限掩盖问题

遇到权限错误时，先检查：

- 当前进程的用户身份。
- 文件和上层目录的权限。
- 所属组、ACL 等其他访问控制因素。

最小权限的意义，在于让实际授权与操作需求相匹配。
