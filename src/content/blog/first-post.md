学习算法时，比起直接记住结论，更有价值的问题是：**输入规模变化时，程序需要做多少工作？**

## 从一个简单的遍历开始

下面的函数寻找数组中的最大值。它不依赖元素是否有序，只需要依次比较。

```cpp
#include <algorithm>
#include <optional>
#include <vector>

std::optional<int> maximum(const std::vector<int>& values) {
    if (values.empty()) {
        return std::nullopt;
    }
    return *std::max_element(values.begin(), values.end());
}
```

这里使用 `std::optional` 表示“可能没有结果”。当输入为空时，调用者可以明确处理这种情况。

## 把输入规模和操作次数联系起来

对于包含 n 个元素的数组，寻找最大值需要 n − 1 次比较，因此时间复杂度是 **O(n)**，额外空间复杂度是 **O(1)**。

| 输入情况 | 需要考虑的问题 |
| --- | --- |
| 空数组 | 是否能明确表达没有结果？ |
| 只有一个元素 | 是否正确返回该元素？ |
| 包含负数 | 是否错误地将初始最大值设为零？ |
| 包含重复值 | 是否影响比较结果？ |

### 写笔记时，保留推导过程

一篇便于回顾的笔记，可以按这样的顺序展开：

1. 描述问题与输入范围。
2. 写出最直接的解法。
3. 分析时间与空间开销。
4. 补充边界条件与反例。
5. 总结适用场景。

## 一个值得留下的问题

如果需要回答很多次区间最大值查询，每次都遍历数组是否合适？

这可以作为后续学习数据结构的切入点。在理解问题之前，不急于选择复杂的工具。
